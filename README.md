# Мода як форма культурного самовираження

React-презентація (Vite + TypeScript + React Three Fiber), зроблена для живого виступу: **темп задає доповідач**.

```bash
npm install
npm run dev      # розробка; клавіша P показує/ховає панель FPS / triangles / draw calls (лише в dev, за замовчуванням прихована)
npm run build    # перевірка типів + збірка у dist/
npm run preview  # перегляд збірки
```

## Керування

| Дія | Результат |
| --- | --- |
| `→` · `Space` · `PageDown` · клік по порожньому місцю слайда · кнопка `›` | наступний слайд (одразу) |
| `←` · `PageUp` · кнопка `‹` | попередній слайд |
| `Home` / `End` | перший / останній слайд |
| `↓` `↑` або `1`–`5` | кроки та образи LOOK всередині слайда (слайд не змінюється) |
| `N` | нотатки доповідача |
| `F` / `Esc` | повний екран / вихід |

Нічого не перемикається саме: **автоплею немає**, увесь текст слайда видно одразу, анімації короткі (≈ 0,2 с) і ніколи не блокують перехід.

## 3D (легкий)
- Один WebGL-канвас на весь сайт; кадри малюються лише там, де на слайді є 3D (`frameloop="demand"`), на інших слайдах рендеринг зупинений.
- Манекен: готові CC0 GLB із 3DAssets.dev (`public/models/`, ≈125 КБ кожна, ≈2,3 тис. трикутників), завантажуються ліниво. Поки модель завантажується, показується легка DOM-заглушка.
- Сукня будується параметрично під виміри цього манекена (`src/scene/fit.ts`, `garments.ts`) ≈ 5 тис. трикутників; без тіней, постобробки, фізики та частинок.
- Манекен «причесано» під час завантаження: гладка голова (перебудована за профілем самої моделі, без виступаючої «маски»), ступні як взуття, чиста кругла основа під обома ступнями замість прута з диском.
- Роздільність 3D обмежена бюджетом ≈2 Мпікс (на дуже великих екранах шар трохи м’якший, але плавний); MSAA вимкнено на дуже великих екранах.
- Якщо GLB не завантажиться — вмикається вбудований запасний манекен (`anatomy.ts`).
- Шрифти (Cormorant Garamond, Inter) лежать у `src/assets/fonts` — без зовнішніх CDN.
